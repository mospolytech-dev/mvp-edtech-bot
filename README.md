# MVP EdTech Bot

> **Telegram-бот для управления учебным процессом: расписание, посещаемость, оценки**

---

## Стек

| Компонент    | Технология           |
|-------------|----------------------|
| Язык         | Python 3.12+         |
| Telegram Bot | Aiogram 3.28         |
| База данных  | PostgreSQL 14+       |
| ORM          | SQLAlchemy 2.0 Async |
| Миграции     | Alembic              |
| Конфигурация | python-dotenv        |

## Быстрый старт

### 1. Клонировать и перейти в папку

```bash
git clone https://github.com/mospolytech-dev/mvp-edtech-bot.git
cd mvp-edtech-bot
```

### 2. Создать виртуальное окружение и установить зависимости

```bash
python -m venv .venv
source .venv/bin/activate        # macOS / Linux
# .venv\Scripts\activate         # Windows

pip install -r requirements.txt
```

### 3. Настроить переменные окружения

```bash
cp .env.example .env
```

Открыть `.env` и заполнить:

```env
BOT_TOKEN=your_telegram_bot_token_here
DATABASE_URL=postgresql+asyncpg://postgres:password@localhost:5432/edtech_db
ADMIN_IDS=123456789,987654321
```

`ADMIN_IDS` — Telegram ID администраторов через запятую. Узнать свой ID можно через @userinfobot.

### 4. Создать базу данных и применить миграции

```bash
python -m scripts.setup_db
```

> PostgreSQL должен быть запущен. Пользователь из `DATABASE_URL` должен иметь право создавать базы данных.

### 5. Запустить бота

```bash
python -m bot.main
```

## Как работает /start

| Кто открывает         | Что видит                              |
|-----------------------|----------------------------------------|
| ID из `ADMIN_IDS`     | Панель администратора                  |
| Новый пользователь    | Форма регистрации                      |
| Заявка на рассмотрении | Сообщение "ожидайте"                  |
| Заявка отклонена      | Сообщение + кнопка "Подать повторно"  |
| Активный студент      | Меню студента                          |
| Активный преподаватель | Меню преподавателя                    |

## Регистрация

Флоу через FSM:

1. Выбор роли — Студент / Преподаватель / Администратор
2. Ввод ФИО (валидация: 2–3 слова, кириллица, каждое с заглавной буквы)
3. **Студент** — выбор группы из списка (2 колонки, пагинация если >8)
4. **Преподаватель** — мультивыбор дисциплин (2 колонки, пагинация если >8)
5. Заявка уходит администратору на одобрение

После отклонения — уведомление с кнопкой "🔄 Подать заявку повторно", старая запись удаляется.

> Дисциплины преподавателя при регистрации сохраняются только в уведомлении администратору, не в БД (MVP).

## Меню по ролям

### 👨‍🎓 Студент

| Кнопка              | Что показывает                                              |
|---------------------|-------------------------------------------------------------|
| 📅 Расписание        | Расписание группы по дням недели (предмет, время, аудитория, преподаватель) |
| ✅ Моя посещаемость  | Статистика (всего / присутствовал / отсутствовал / опоздал / %) + история |
| 📊 Мои оценки        | Оценки сгруппированы по дисциплинам со средним баллом      |

### 👨‍🏫 Преподаватель

Флоу: **Расписание → выбрать пару → действие**

| Действие                  | Что происходит                                             |
|---------------------------|-------------------------------------------------------------|
| ✅ Отметить посещаемость   | Список студентов с тоглом ⬜→✅→❌→⏰, сохраняется на лету |
| 📊 Выставить оценки        | Список студентов → выбрать → оценка 1–5                   |

### 👨‍💼 Администратор

| Раздел           | Функционал                                              |
|------------------|---------------------------------------------------------|
| 👥 Пользователи   | Список преподавателей и студентов раздельно             |
| 📋 Заявки         | Список → карточка → одобрить / отклонить                |
| 🏫 Группы         | Просмотр, создание, удаление (пагинация)                |
| 📚 Дисциплины     | Просмотр, создание, удаление (пагинация)                |
| 📅 Расписание     | Просмотр всех занятий, добавление (выбор пары кнопками) |
| 🧪 Тест-режим     | Просмотр интерфейса студента / преподавателя            |

## Тест-режим (для разработчиков)

Позволяет проверить интерфейс студента и преподавателя без второго Telegram-аккаунта.

**Как использовать:**

1. `/start` → панель администратора
2. **🧪 Тест-режим**
3. **🌱 Заполнить тестовые данные** — создаёт группы, дисциплины и студентов если их ещё нет (идемпотентно)
4. Выбрать роль:
   - **👨‍🏫 Войти как преподаватель** — роль `teacher`, создаются 3 тестовых занятия (Пн/Ср/Пт)
   - **👨‍🎓 Войти как студент** — роль `student`, группа 253-324, автоматически сидируются посещаемость (4 недели назад) и оценки (2 штуки на занятие)
5. `/start` — мгновенный возврат в админку (проверка `ADMIN_IDS` срабатывает раньше роли из БД)

> Тест-режим изменяет запись только для твоего `telegram_id`. На других пользователей не влияет.
