# MVP EdTech Bot

> **MVP Telegram-бот для системы управления учебным процессом**

---

## О проекте

Telegram-бот для автоматизации учебного процесса: расписание, посещаемость и оценки — всё в одном месте, прямо в мессенджере. Проект разрабатывается командой как студенческий MVP с прицелом на production-масштабирование.

## Цель проекта

Создать удобный инструмент для студентов и преподавателей, который позволяет:
- быстро получать актуальное расписание занятий
- отслеживать посещаемость в реальном времени
- просматривать текущие оценки и успеваемость
- получать уведомления об изменениях в расписании

## Запуск проекта

### 1. Клонировать репозиторий

```bash
git clone https://github.com/your-org/mvp-edtech-bot.git
cd mvp-edtech-bot
```

### 2. Создать файл окружения

```bash
cp .env.example .env
```

Открыть `.env` и заполнить переменные:

```env
BOT_TOKEN=your_telegram_bot_token_here
DATABASE_URL=postgresql+asyncpg://postgres:password@localhost:5432/edtech_db
```

> Токен бота получить у [@BotFather](https://t.me/BotFather) в Telegram.

### 3. Установить зависимости

```bash
python -m venv .venv
source .venv/bin/activate        # Linux / macOS
# .venv\Scripts\activate         # Windows

pip install -r requirements.txt
```

### 4. Настроить базу данных

Убедиться, что PostgreSQL запущен, и создать БД:

```sql
CREATE DATABASE edtech_db;
```

### 5. Применить миграции

```bash
alembic upgrade head
```

### 6. Запустить бота

```bash
python -m bot.main
```
