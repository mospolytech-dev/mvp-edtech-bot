# MVP EdTech Bot

> **Telegram-бот для управления учебным процессом: расписание, посещаемость, оценки**

---

## Стек

| Компонент     | Технология              |
|--------------|-------------------------|
| Язык          | Python 3.12+            |
| Telegram Bot  | Aiogram 3.28            |
| База данных   | PostgreSQL 14+          |
| ORM           | SQLAlchemy 2.0 Async    |
| Миграции      | Alembic                 |
| Конфигурация  | python-dotenv           |

## Быстрый старт

### 1. Клонировать и перейти в папку

```bash
git clone https://github.com/mospolytech-dev/mvp-edtech-bot.git
cd mvp-edtech-bot
```

### 2. Создать виртуальное окружение и установить зависимости

```bash
python -m venv .venv
source .venv/bin/activate        # macOS / Linux
# .venv\Scripts\activate         # Windows

pip install -r requirements.txt
```

### 3. Настроить переменные окружения

```bash
cp .env.example .env
```

Открыть `.env` и заполнить:

```env
# Токен бота — получить у @BotFather
BOT_TOKEN=your_telegram_bot_token_here

# Строка подключения к PostgreSQL
DATABASE_URL=postgresql+asyncpg://postgres:password@localhost:5432/edtech_db

# Telegram ID администраторов через запятую (узнать через @userinfobot)
ADMIN_IDS=123456789,987654321
```

### 4. Сгенерировать миграцию

```bash
alembic revision --autogenerate -m "init"
```

### 5. Создать базу данных и применить миграции

Скрипт сам создаст БД `edtech_db` (если не существует) и применит все миграции:

```bash
python -m scripts.setup_db
```

> PostgreSQL должен быть запущен. Пользователь из `DATABASE_URL` должен иметь право создавать базы данных (обычно это `postgres`).

### 6. Запустить бота

```bash
python -m bot.main
```

## Как работает /start

| Кто открывает | Что видит |
|---|---|
| Telegram ID из `ADMIN_IDS` | Панель администратора |
| Новый пользователь | Форма регистрации |
| Заявка на рассмотрении | Сообщение "ожидайте" |
| Заявка отклонена | Сообщение + кнопка "Подать повторно" |
| Активный студент | Меню студента |
| Активный преподаватель | Меню преподавателя |

---

## Регистрация

Флоу через FSM:

1. Выбор роли — Студент / Преподаватель / Администратор
2. Ввод ФИО (валидация: 2–3 слова, кириллица, каждое с заглавной буквы)
3. **Студент** — выбор группы из списка (2 колонки, пагинация если >8)
4. **Преподаватель** — мультивыбор дисциплин (2 колонки, пагинация если >8)
5. Заявка уходит администратору на одобрение

После отклонения пользователь получает уведомление с кнопкой "🔄 Подать заявку повторно" — старая запись удаляется, регистрация начинается заново.

> Выбранные преподавателем дисциплины отображаются только в уведомлении администратору и не сохраняются в БД (MVP). Постоянная связь появится позже через таблицу `teacher_subjects`.

## Админ-панель

Доступна автоматически при `/start` для пользователей из `ADMIN_IDS`.

| Раздел | Функционал |
|---|---|
| 👥 Пользователи | Список преподавателей и студентов раздельно |
| 📋 Заявки | Список ФИО → карточка с данными → одобрить / отклонить |
| 🏫 Группы | Просмотр, создание и удаление групп (пагинация) |
| 📚 Дисциплины | Просмотр, создание и удаление дисциплин (пагинация) |
| 📅 Расписание | Просмотр и добавление занятий |

> Администраторы определяются по `ADMIN_IDS` в `.env`. При одобрении заявки с ролью "Администратор" бот напоминает добавить ID в `.env` и перезапустить бота.
