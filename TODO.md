## GitHub Workflow

| Ветка               | Назначение                                          |
|---------------------|-----------------------------------------------------|
| `main`              | Стабильный код, слияние только через PR после ревью |
| `feature/<название>` | Одна задача или функция на ветку                   |

**Формат коммитов:**
```
feat: добавить панель студента
fix: исправить пагинацию при отметке посещаемости
refactor: вынести форматирование расписания в отдельную функцию
chore: обновить requirements.txt
docs: обновить README
```
